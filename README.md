# Vela Peptide — Complete Responsive Website

A self-contained Next.js website for Vela Peptide, designed for phone, tablet and laptop.

## Included
- Premium futuristic aquaculture homepage
- Local hero, product, research and fish-species imagery
- Catla, Rohu, Tilapia, Pangasius, Shrimp, Carp and Seabass section
- Products, applications, research, sustainability and contact sections
- Responsive mobile navigation
- Working quote/enquiry modal (front-end demo)
- No external image URLs required

## Run
npm install
npm run build
npm run start
